# Task 4 – Version-Controlled DevOps Project with Git

## Objective

The objective of this task is to manage a DevOps project using Git and GitHub best practices.

## Tools Used

- Git
- GitHub
- Git Bash

## Git Workflow

This project follows a feature-based Git workflow:

main → dev → feature → Pull Request → dev → Pull Request → main

## Branches

- `main` – Stable/main branch
- `dev` – Development branch
- `feature/project-update` – Feature development branch

## Git Best Practices Demonstrated

- Git repository initialization
- Meaningful commits
- Multiple branches
- Feature-based development
- Pull Requests
- Branch merging
- `.gitignore`
- Git tags
- GitHub repository management
